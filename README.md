# موقع مشروع مساكن الأخيار

موقع تعريفي بالمشروع السكني لمؤسسة مساكن الأخيار للمقاولات العامة في حي النخيل ببريدة.
الموقع صفحة واحدة ثابتة (HTML/CSS/JS) ولا يحتاج خادمًا أو قاعدة بيانات.

## الأقسام
- الواجهة الرئيسية مع منظور العمارة وأرقام المشروع
- عن المشروع وبيانات الملكية والقطعة
- مميزات المشروع
- نماذج الشقق A / B / C مع المخططات ثلاثية الأبعاد
- اختيار الشقق: 36 شقة حسب الدور والنموذج، مع نافذة تفاصيل لكل شقة
- المخططات المعمارية (الدور المتكرر، الأرضي، الملحق) وجدول مكونات البناء
- الموقع وحدود القطعة والخريطة
- نموذج تسجيل الاهتمام

## التحديث
كل البيانات القابلة للتعديل موجودة في `assets/js/data.js`:

| ما تريد تغييره | أين |
|---|---|
| رقم الجوال والواتساب والبريد | `SITE_CONFIG` (`phoneDisplay`، `phoneIntl`، `email`) |
| حالة الشقق (متاحة / محجوزة / مباعة) | `statusOverrides`، مثال: `{ 5: "sold", 12: "reserved" }` |
| موقع الخريطة | `SITE_CONFIG.mapLat` و `mapLng` |

عند ضبط `phoneIntl` يظهر زر واتساب العائم، ويُرسَل نموذج الاهتمام كرسالة واتساب.
إذا لم يُضبط أي رقم أو بريد، يعرض النموذج رسالة توضح أن وسيلة الاستقبال غير مربوطة بعد.

## التشغيل محليًا
```bash
python3 -m http.server 8000
```
ثم افتح http://localhost:8000

## النشر
يمكن رفع المجلد كما هو على أي استضافة ثابتة (GitHub Pages أو Netlify أو استضافة cPanel).
